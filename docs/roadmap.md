## Этап 2 — полезная маршрутизация
- [ ] Добавить профили задач как подсказки пользователю.
- [ ] Добавить preference-based выбор по доступности, задержке и необязательным тарифам.
- [ ] Поддержать произвольные совместимые пользовательские endpoints.
- [ ] Добавить opt-in fallback с явной настройкой.
- [ ] Добавить метрики usage/latency и оценку цены там, где данные доступны.
- [ ] Собрать тестовый набор для сравнения маршрутов.

**Критерий выхода:** пользователь понимает, почему выбран маршрут, и может отключить автоматический выбор/fallback.

## Этап 3 — пилот
- [ ] Добавить интеграционные тесты и CI.
- [ ] Проверить поведение при недоступности endpoint.
- [ ] Провести нагрузочный тест.
- [ ] Документировать локальные подключения и границы ответственности за их эксплуатацию.
- [ ] Проверить, что логи не содержат секретов и содержимого запросов по умолчанию.

**Критерий выхода:** понятны ограничения, ошибки наблюдаемы, поведение контролируется пользователем.

## Не входит в первый MVP
- Хостинг или загрузка весов локальных моделей.
- Централизованная оплата вычислений за пользователя.
- Обязательный список поддерживаемых моделей.
- Скрытая маршрутизация или автоматическое переключение без разрешения пользователя.
- Собственная GPU-инфраструктура.
